# Random Password Generator

A responsive Random Password Generator created as **Task 17** of my
**Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project is a browser-based password generator that creates a
random password based on the selected length and character types.

Users can choose uppercase letters, lowercase letters, numbers, and
symbols and then generate a password instantly.

A copy-to-clipboard button is also provided.

## 🎯 Objective

The objective of this task was to practice:

- HTML checkboxes
- JavaScript string building
- Randomization
- Form handling
- DOM manipulation
- Clipboard API
- Conditional logic

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Adjustable password length
- Length range from 4 to 30
- Uppercase character support
- Lowercase character support
- Number support
- Symbol support
- Random password generation
- Copy-to-clipboard button
- Empty-selection validation
- Responsive design
